## ⚙️ GitHub Pages 开启方式

1. 进入仓库主页的 **Settings**（设置）。
2. 在左侧菜单点击 **Pages**。
3. 在 **Build and deployment** 下的 **Branch** 选择 `main` 分支，目录选择 `/ (root)`。
4. 点击 **Save**。
5. 等待 1~2 分钟，部署完成即可在全球任意设备（手机或电脑）访问。
